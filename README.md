# ❤️ I Love You In Every Language — Aesthetic Multilingual Heart

An interactive, aesthetic web experience displaying "I love you" in over 126 languages sculpted into the shape of a glowing heart.

## ✨ Features

- **Geometric Heart Typography**: Words across 126+ languages arranged to form a heart shape with top lobes and lower taper, mirroring and elevating the reference visual.
- **Dynamic Language Morphing**: Individual phrases flip and morph in 3D into new languages with radiant neon flashes.
- **Interactive 3D Parallax & Heartbeat**: The entire heart responds to cursor movements with realistic 3D perspective depth and double-heartbeat pulsing.
- **Radiant Love Wave**: A golden-neon cascade travels across the heart rows.
- **Interactive Tooltip & Speech Synthesis**: Hover or tap any word to reveal its country flag, native script, English name, and phonetic pronunciation. Click to hear it spoken out loud using browser speech synthesis!
- **Celestial Backdrop**: Twinkling stardust particle field, floating embers, and ambient central heartbeat aura.
- **5 Aesthetic Themes**:
  - 🌹 *Ruby Passion* (Classic Crimson & Ruby Bloom - like reference)
  - 🌸 *Rose Gold* (Soft Pink, Champagne & Rose Quartz)
  - 🌌 *Cosmic Violet* (Deep Indigo, Electric Magenta & Cyan)
  - 🍯 *Golden Honey* (Candlelight Amber & Warm Gold)
  - 🌊 *Northern Aurora* (Emerald & Celestial Mint)
- **Ambient Piano Synthesizer**: Built-in Web Audio API romantic ambient sound generator.
- **Personalized Dedication & Share Links**: Customize "For [Name]" which automatically creates a shareable link via URL parameters (`?to=Name&theme=ruby`).
- **126+ Language Directory**: Searchable explorer modal with every language and phrase.

## 🚀 Quick Start

### Option 1: Direct Browser
Simply double-click `index.html` to open it in any modern web browser.

### Option 2: Python Local Server
Run:
```bash
python server.py
```
This automatically launches your browser at `http://localhost:8000`.
